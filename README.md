# 2027日历·汪苏泷

这是现有 [2027日历](https://zunyaner.github.io/calendar-2027/) 的汪苏泷主题版：功能相同，首页换成演唱会现场照，名言换成歌词短句。主题色用蜜桃粉 #FFB7C5（公开资料只写应援色是粉色，没有官方色号；需要对比度的按钮用更深的桃粉 #BE4E68）。每个月的日历卡片会垫一张半透明的现场照片，按月轮换。

这是个人非官方主题，与艺人及经纪公司无关。原来的日历不受影响，可以同时装在桌面上。

本仓库里只有休班日期、农历节气、歌词短句和已注明来源的现场照片，**不包含任何个人待办**。你在网页里添加的事项只保存在这台手机上，不会上传。两个主题版的事项是分开存放的。

## 在 iPhone 上使用

1. 用 **Safari** 打开：<https://zunyaner.github.io/calendar-wsl/>
2. 点底部分享按钮，选「添加到主屏幕」。
3. 回到桌面，打开「2027日历·汪苏泷」（图标简称「泷日历」）。

用法与原版相同：首页有「本月」和 2027 年全年总览，点某个月进入详情，点某一天可以添加事项。月份范围是 2026 年 11 月至 2027 年 12 月。

## 订阅公司行事历

订阅地址与原版相同（内容一样）：

- `webcal://zunyaner.github.io/calendar-wsl/company-2027.ics`
- <https://zunyaner.github.io/calendar-wsl/company-2027.ics>

订阅名：膳魔师行事历 2026.11–2027。iPhone 订阅的日历常常不会弹出提醒，请以日历里的全天事件为准。

## 如何更新已安装的主屏幕应用

关掉桌面上的图标再打开，一般就会换成新版本。如果还是旧的，用 Safari 再打开一次网页，等它加载完成后，再从主屏幕打开。以前添加的事项还在。
